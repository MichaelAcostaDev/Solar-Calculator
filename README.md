# ☀️ Solar Calculator

A modern calculator built with **HTML, CSS and Vanilla JavaScript** inside a single HTML file.

---

## About 🧠

Solar Calculator is a lightweight project created to practice JavaScript fundamentals while designing an interface inspired by modern code editors.

Instead of relying on frameworks or external libraries, the entire application was developed using only HTML, CSS and Vanilla JavaScript, making the project easy to understand, modify and extend.

Everything is contained in a single file (`calculator.html`), demonstrating how much can be achieved with the core technologies of the web.

---

## Features 📌

- Modern code editor inspired interface
- Responsive layout
- Basic arithmetic operations
- Decimal support
- Mathematical constant (π)
- Lightweight and fast
- No frameworks
- No external dependencies

---

## Built With 🤖

- HTML5
- CSS3
- Vanilla JavaScript (ES6)

---

## Getting Started 👍

Clone the repository:

```bash
git clone https://github.com/your-username/Solar-Calculator.git
```

Open:

```
calculator.html
```

using any modern browser.

No installation is required.
